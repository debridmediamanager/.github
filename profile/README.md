### Debrid Media Manager + zurg + rex

Three projects for debrid accounts and Usenet.

| | |
|---|---|
| **[Debrid Media Manager](https://debridmediamanager.com/)** | Find movies and shows and keep them in your debrid library. Free in the browser. [Source](https://github.com/debridmediamanager/debrid-media-manager) |
| **[zurg](https://zurg.debridmediamanager.com/)** | Every debrid account and Usenet in one folder that Plex, Jellyfin and Emby read like a normal drive. [Public release](https://github.com/debridmediamanager/zurg-public). Nightlies are for sponsors |
| **[rex](https://rex.debridmediamanager.com/)** | Any source. Every Plex app. A media server that owns no files. Free for personal use. Addons: [rex-stremio](https://github.com/debridmediamanager/rex-stremio) and [rex-live-sports](https://github.com/debridmediamanager/rex-live-sports) |
